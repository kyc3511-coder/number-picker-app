# 번호 뽑기

범위와 개수를 지정해 무작위 번호를 뽑는 작은 웹앱입니다. 설치나 서버 없이 브라우저에서 동작하며, 번호는 외부로 전송되지 않습니다.

## 기능

- 최솟값·최댓값·개수 설정
- 중복 허용 여부 선택
- 최근 5회 결과 확인
- 결과 복사
- 모바일 및 키보드 접근성 지원

## 로컬 실행

`index.html`을 브라우저에서 열면 됩니다. 로컬 서버를 쓰려면 저장소 루트에서 `npx serve .`를 실행하세요.

## 배포

GitHub 저장소의 **Settings → Pages**에서 **Deploy from a branch**, `main`, `/ (root)`를 선택하면 배포됩니다.
